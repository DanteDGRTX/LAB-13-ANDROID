# LAB 13 Android — Animación de visibilidad

Proyecto de Android Studio con Jetpack Compose. El ejercicio usa `AnimatedVisibility` para alternar la aparición de un cuadro de color. La entrada combina `fadeIn` con `expandVertically`; la salida combina `fadeOut` con `shrinkVertically`.

## Ejecutar

1. Abre esta carpeta en Android Studio y espera la sincronización de Gradle.
2. Ejecuta la configuración `app` en un emulador o dispositivo Android.
3. Pulsa **Mostrar cuadro** y **Ocultar cuadro** para observar las transiciones.

Tecnologías: Kotlin, Jetpack Compose, Material 3 y Android Gradle Plugin.
